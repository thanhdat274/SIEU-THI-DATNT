# TÀI LIỆU KỸ THUẬT TIỆM TẠP HÓA ĐẦU HẺM

Thư mục này chứa toàn bộ tài liệu kiến trúc, thiết kế game, đặc tả API và lược đồ cơ sở dữ liệu.

- `docs/game-design/`: Chi tiết kịch bản, vòng lặp chơi, hệ thống vật phẩm và NPC.
- `docs/architecture/`: Kiến trúc Monorepo, ECS, PixiJS renderer, Zustand UI.
- `docs/api/`: Đặc tả REST API chuẩn cho NestJS backend (Phase 7).
- `docs/database/`: Lược đồ Dexie IndexedDB và MongoDB Atlas.
- `docs/implementation/`: Hướng dẫn triển khai chi tiết từng giai đoạn.
